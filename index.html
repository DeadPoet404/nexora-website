01 / THE PRINCIPLE

Messages find a way
through the mesh.

Meshrelay is built around a simple idea: nearby devices can form a local communication fabric. A message may pass from one peer to another, extending its path beyond a single direct connection.

01 — DISCOVER

Find nearby peers

Bluetooth Low Energy discovery helps devices find other participating devices in range.

02 — CONNECT

Form local links

Nearby peers establish connections that become links in the wider mesh.

03 — RELAY

Pass it along

Messages can be forwarded through intermediate peers using the routing layer.

04 — DELIVER

Reach another peer

The mesh creates possible paths between devices without requiring a conventional internet route.

02 / BUILT INTO Meshrelay

Tools for a more
connected nearby world.

A look at the capabilities implemented in the current project.

⌁

Offline-first messaging

A chat experience designed around nearby device communication, message persistence and relay queues.

◎

Multi-hop routing

Message chunking, forwarding, routing decisions and duplicate detection support movement across peers.

⌗

Peer identity

QR-based identity exchange, fingerprints and peer trust states help users inspect who they connect with.

✳

SOS broadcast

An emergency broadcast flow can include location coordinates when available and repeat broadcasts through the mesh.

◉

Live mesh view

A deterministic network visualization presents topology, peer states, connections and animated message hops.

05 / GOOD TO KNOW

Questions, answered.

Does Meshrelay need an internet connection?

The app is designed around nearby-device communication over Bluetooth Low Energy. Actual behavior depends on device support, permissions, range and the current implementation.

Which devices are supported?

The current project is Android-first and built with Flutter. Check the release notes for tested Android versions and device requirements.

Are messages end-to-end encrypted?

Not currently. The project's security documentation states that message contents and SOS coordinates are presently plaintext. Do not use Meshrelay for sensitive communications.

Can I rely on Meshrelay in an emergency?

No. SOS functionality is experimental and delivery is not guaranteed. Keep established emergency services and communication methods available.

Is the source code available?

Yes. Explore the Meshrelay source repository on GitHub to inspect the implementation and follow development.
